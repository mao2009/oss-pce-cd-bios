# EX_BINBCD 入力被覆の計測計画（非実行・BLOCKED）

Issue #310（親 #70）。対象は System Card の slot `$3C` / 候補 `$E0B4` の純正 EX_BINBCD である。
本書と `tests/fixtures/ex-binbcd-measurement-plan.json` は**計測計画とフィクスチャ定義のみ**であり、
純正ルーチンは実行しない（`execution: NOT_RUN`、`reference_jsr: NOT_CALLED`）。
ABI は未確定（`abi_status: BLOCKED_ABI`、`release_eligible: false`）。

## 状態

| 項目 | 状態 | 根拠 |
|---|---|---|
| 呼び出し側から見た入力 | UNKNOWN | HuC `cd_playmsf` の引数は [#150 調査](research/150-cd-play-abi.md) で CALLER 証拠として作業 RAM `$20F8-$20FF` に置かれると記録されるのみで、物理 A ではない。EX_BINBCD の入力レジスタを示す出典はない |
| 戻り値・レジスタ保存・フラグ | UNKNOWN | 出典なし |
| 範囲外（> 99）の挙動 | UNKNOWN | 出典なし。推測で確定しない |
| 純正 `$E0B4` の実行 | **BLOCKED** | 未承認 JSR。#173（JSR 監視の fail-closed 境界）と #228（gate）の承認が前提 |

凡例: UNKNOWN＝期待値の出典なし、NOT_RUN＝未実行、BLOCKED＝ゲート未承認。

## 入力被覆

観測対象の入力は 0, 1, 9, 10, 99, 100, 127, 128, 255 の 9 点である。
選定理由は境界（0、一桁上限 9、桁上がり 10、二桁上限 99）、二桁範囲外の先頭（100）、
符号付きバイトの境界（127/128）、8 ビット最大（255）である。

| 入力 | 理由 | 範囲 | 期待値 |
|---|---|---|---|
| 0 | 下限 | 0..99 | UNKNOWN |
| 1 | 最小の非零（一の位のみ） | 0..99 | UNKNOWN |
| 9 | 一桁上限 | 0..99 | UNKNOWN |
| 10 | 最初の桁上がり | 0..99 | UNKNOWN |
| 99 | 二桁上限 | 0..99 | UNKNOWN |
| 100 | 二桁範囲外の先頭 | > 99 | UNKNOWN（範囲外、未特性化） |
| 127 | 符号付きバイトの正の最大 | > 99 | UNKNOWN |
| 128 | ビット 7 が立つ最初の値 | > 99 | UNKNOWN |
| 255 | 8 ビット最大 | > 99 | UNKNOWN（範囲外、未特性化） |

「範囲」列は本計画が仮に分類したものである。純正 EX_BINBCD が 0..99 を有効範囲として扱うかどうかも未確認である。

## 観測項目

各入力について、計測時に次の項目を記録する。これらの期待値は現時点では全て UNKNOWN である。

- **A / X / Y**: 呼び出し後の値。入力前の値と比較して保存の有無を判定する。
- **P**: C / Z / N / V / D / I / T の各フラグ。
- **SP**: 呼び出し前後のスタックポインタ。
- **MPR0-MPR7**: 呼び出し前後のバンク設定。
- **関連 RAM**: 測定時に定義する。今は未定義である。
- **戻り PC**: スタック上の戻りアドレス。

## 純正 JSR を実行しない範囲

- 純正 `$E0B4` への JSR は計画段階では実行しない。実行は #173 / #228 の承認後に限る。
- ROM のジャンプテーブルへの配線は行わない。`DEV_CALLABLE` へのラベル付与も行わない。
- 自作ルーチン（`src/ex_binbcd.s`）の結果は「自作ルーチンの検証」であり、BIOS ABI の証拠ではない。

## 既存テストとの重複

本計画では既存テストと重複する検証を追加しない。

- ホスト: `tests/host/test_ex_binbcd.py` が 0, 9, 10, 99, 100, 255 の自作モデル値を確認している。
- 実コア（opt-in）: `tests/integration/geargrafx_ex_binbcd.py` が 0..255 の全入力を自作ルーチンで照合する（#331 の `routine-real-core`）。

1, 127, 128 は実コア照合（tests/integration/geargrafx_ex_binbcd.py、0..255 走査）の対象に含まれる。本 PR では未実行。これは自作ルーチンの結果にすぎない。純正側の観測は本計画で初めて対象になる。

## 計測の前提（将来の作業）

1. #173 / #228 の承認を得る。承認前に純正 `$E0B4` を呼ばない。
2. 計測ハーネスは DEV ROM の `$E800-$EFFF` テストオーバーレイ方式（`docs/testing.md`）を参考にする。純正ルーチンの呼び出し経路は別途設計する。
3. 記録は pinned Geargrafx で行い、ツールの版と ROM の SHA-256 を残す。
4. 実機の挙動は証明されない。Geargrafx の結果は観測であり、ABI 互換の証拠ではない。
