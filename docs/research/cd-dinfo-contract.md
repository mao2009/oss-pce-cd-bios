# CD_DINFO（スロット `$0B`、候補エントリ `$E021`）呼出側 ABI・呼出契約の根拠台帳（Issue #234）

**状態: 呼出先（System Card の callee）の ABI は未確定。ROM 実装なし。**
親 Issue #20、対象 Issue #234（Contract）。spec=HYPOTHESIS、provenance=PENDING、implementation=NOT_STARTED、verification=NOT_RUN。
**callee 側: BLOCKED_ABI。release_eligible=false。DEV_CALLABLE にしない。**

本台帳は、公開の呼出側ソースから読める事実と、呼出先の仮説・未確定を分けて記録する。
名前（`cd_dinfo`）や呼出側のコメントから呼出先の ABI を導かない。未確定の欄には値を補わない。
照会種別（`_al`）は種別ごとに行を分け、BCD トラック・入力値・4 バイト出力の候補は根拠別に書く。

## 1. 規則

状態の意味:

- `SOURCE_FACT`: 固定版の公開ソースに書かれた事実。**呼出側（caller）の記述**か、**名前・入口の宣言**に限る。呼出先の振る舞いには付けない。
- `HYPOTHESIS`: 作者のコメント（試験プログラムの仕様記述）や、呼出側の入力源からの推測。実行で確認していない。
- `UNKNOWN`: 出典が不足している、または出典同士が食い違う。値の欄は `UNKNOWN` と書く。
- `BLOCKED_ABI`: 呼出先の ABI が未確定で、実行による測定もできない（実行可能な callee がない）。

禁止事項:

- `VERIFIED` と `OBSERVED` は使わない。呼出先を実行していないため、どの行にも付けられない。
- `PASS` と `DEV_CALLABLE` は使わない。CD_DINFO は callable として実装されていない。
- `side` が `callee` の行は `HYPOTHESIS` / `UNKNOWN` / `BLOCKED_ABI` のみ。呼出側のソースから callee の事実を導かない。
- `SOURCE_FACT` の根拠は一次出典（S1〜S3）に限る。利用許諾が確認できない出典（S4）や名前のみの出典（S5）、リポジトリ内の棚卸し（S6）だけを根拠にしない。

## 4. 出典間の食い違い（明示）

1. **戻り値の判定レジスタ**: 呼出側 S2 は Z で分岐し、作者コメント（S2 2014、S3 1579）は Y・Z・N を挙げる。利用許諾未確認の S4 は `cmp #$00` で A を判定する。どのレジスタが結果を運ぶかは F18・F19 で UNKNOWN のまま残す。
2. **出力バッファの位置**: S4 は BX に `cd_buf` を設定して BIOS に渡すように読める。BSL-1.0 の S2・S3 は BX を設定せず、固定の `scsi_recv_buf` から読む。S2・S3 の固定バッファは試験側の実装であり、BIOS の出力先の証拠ではない（F11・F12）。
3. **種別 3**: S2 の作者コメントは「文書化されているが、使えない値（LBA ではないゴミ）を返す」と書く。作者の観測であり、実行で未確認。種別 3 の行は立てず、F07 の範囲に含める（HYPOTHESIS 扱い）。
4. **トラックの形式**: S2 は種別 0 の結果（BCD）を `_ah` に入れる。S4 は 2 進から BCD へ変換してから `_ah` に入れる。両方とも BCD を指すが、BIOS がそれを要求するかは F09 で未確認。
5. **版の違い**: 固定版の出典に、System Card の版（1.0、2.x、3.0）を示す記述はない。版による違いは確認できない（UNKNOWN）。

## 5. 除外・未転載

- 出典の本文（コード、表、命令列）は転載しない。台帳は行番号と作者の記述の要旨だけを記す。
- ROM の内容、逆アセンブル、BIOS のバイト列は読んでいない。`./rom/` は参照していない。純正 `syscard3.pce` は使わない。
