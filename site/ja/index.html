Open-source firmware / PC Engine CD

System Cardを、誰もが使えるOSSへ。

PCエンジン / TurboGrafx-CD向けの再配布可能なSystem Card BIOS代替実装を、独自コードと適切にライセンスされたOSSで開発しています。動作を確認できた範囲と、まだ分からない範囲を明確に公開します。

01 / ミッション

プラットフォームを残す。
ファームウェアを開く。

まず目指すのはSuper System Card 3.0のソフトウェア互換性です。独自にビルド・検証・再配布できるBIOSを育て、将来的に正規のゲームソフトを楽しむために別途プロプライエタリBIOSを用意する必要性を減らします。純正ROMや市販ゲームデータは配布しません。

検証基盤の構築

M1 / 進行中

呼び出せるBIOS API

DEV実装はMA_MUL16S（$4F）を含む9件。純正ABI VERIFIEDは0/81で、CDサービスの呼出可能な互換実装はありません。

M2 / 未達成

自作CDプログラム起動

合成CDからRAMへコードを読み込み実行できていますが、BIOSの起動・サービス経路を通したものではありません。

M3 / 未検証

市販ゲームとの互換性

市販ゲームの起動、別エミュレータとの照合、実機での互換性はまだ確認できていません。

重要：DEV実装9/81、オーナー承認DEV_CALLABLE 0、純正ABI VERIFIED 0/81、純正JSR許可0/81。全81件の準備状態はNOT_READYで、互換BIOSリリースもBLOCKEDです。

2026-10-22の統合：MA_DIV16U DEV実装と合成スタック実験。MPR1=$FFの違反を入口ガードで検出しても、JSRのpush等で先にVDCへ副作用が出るため、#473・#459・#367は未解除です。#475と#477は未マージDraftで、参照ROMのSHA同一性（#476）も未確定。『真・女神転生』は今後のGeargrafx検証対象であり、起動済みではありません。

2026-10-20 の更新：未監視書込み経路と副作用前遮断プローブ、測定点とログ、契約項目と証拠の照合、Pages権限分離と成果物公開ガードを統合。ただし参照JSRとBIOSリリースのゲートは閉じたままです。

✓

Geargrafx実コアで観測済み

EX_GETVERのcold/warm呼び出し・復帰、合成CDのREAD(6)からRAMへの転送、独立した初期化診断など。

05 / よくある質問

今、何ができるの？

検索やAIによる案内でも誤解が起きないよう、実装済みの機能と未検証の範囲を分けて説明します。

01 / 対応状況

実際のゲームで使えるBIOS？

まだ使えません。256KiBの開発用ROMには開発専用の実装が9件（EX_GETVER、EX_BINBCD、EX_BCDBIN、MA_MUL8U、MA_MUL8S、MA_MUL16U、MA_DIV16S、MA_DIV16U、MA_MUL16S。いずれも承認・ABI検証は未了）あり、残り72スロットは未実装です。市販ゲームの互換性や配布可能な製品版は未達成です。

02 / 検証

どこまで動作確認した？

Geargrafx実コアでEX_GETVERの復帰、MA_DIV16UなどのDEV演算API、合成CD読み込みを検証。別の合成スタック実験ではI/O領域へのpushの危険性も観測しました。純正ABI互換性やゲーム起動の証明ではありません。PR #174 を参照してください。

03 / 参加

開発に参加するには？

GitHub Issuesから仕様調査、テスト、独自実装に取り組めます。参加方針を確認し、純正BIOSデータをアップロードしないでください。

オープンなBIOS開発に参加しませんか。

Issueの調査、実測の再現、範囲を絞ったPR。第三者が確かめられる小さな成果の積み重ねが、このプロジェクトを前に進めます。
