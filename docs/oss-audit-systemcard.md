## HuCC / HuC

Repository: https://github.com/pce-devel/huc

Revision: `54f5c73606c1e7142e8095c727cab2767e2b3cb3`; verified local HEAD.
Target files: System Card `.asm/.h`, `pcengine.inc`, `core.inc`, startup,
kernel and stage1 loader; exact paths/hashes below.

The System Card wrapper headers name John Brandwood, copyright 2024; core
headers name John Brandwood, 2021–2024. Those headers specify BSL-1.0.
`pcengine.inc` specifies BSL-1.0 without a named copyright holder in its header;
its ownership lineage remains unresolved. The root LICENSE describes mixed,
partly uncertain historic origins and a Simplified BSD grant limited to Ulrich
Hecht's changes, copyright 2014. Do not apply that grant to the whole SDK.
The included BSL text was read at `examples/asm/elmer/LICENSE_1_0.txt`.

Dependency boundary: wrappers use PCEAS syntax/macros and System Card services;
`system` calls `call_bios`; loaders use `get_file_lba/get_file_info`,
`_add_sectors`, `map_bp_to_mpr34`, overlay directory/state and runtime return
macros. `core.inc` includes `pceas.inc`, `pcengine.inc` and `core-config.inc`;
startup/kernel depend on configured memory layout, hooks, runtime and generated
CD directory structures. A complete transitive audit has not been performed.

Fit: excellent evidence of caller expectations and work-RAM labels; wrappers
are not firmware services. They target the HuCC/PCEAS runtime, not ca65 or a
replacement BIOS. Caller saves and mapping fixes cannot be adopted as callee
preservation. No port or integration was made.

Conditional obligations if a selected BSL unit is later cleared: retain its
copyright, grant, disclaimer and license in source/copies/derivative works;
BSL exempts copies solely in machine-executable object form generated by a
source-language processor from its notice-inclusion requirement. That does
not clear dependencies or mixed SDK origins. A selected BSD-covered unit has
its own source/binary notice obligations. Project source/release policy still
requires attribution and exact adoption review. Current disposition PENDING.

## Hu-Go!

Repository: https://github.com/mckayemu/hugo

Revision: `64ed226da2288738781743eeef228c069e8973a4`; fetched into an external
detached checkout and verified HEAD. Targets: `bios.c`, `cd.c`, `cd.h`, `pcecd.c`.

`COPYING` states default GPL version 2 and explicitly excepts `pcecd.c` under
modified BSD. At this pin the named `LICENSE.gpl` and `LICENSE.bsd-modified`
files are absent. `pcecd.c` embeds a three-condition BSD-style text including
source/binary notice retention and no author endorsement, but its header does
not identify the author/copyright holder referred to by that text. `bios.c`
and `cd.c` have no individual license/copyright attribution in the inspected
opening headers. `AUTHORS` attributes fpce to Bero, Xpce improvements to Hmmx,
subsequent work to Zeograd and contributors, including Nyef's CD emulation;
it does not establish ownership of each target file. File origin and complete
license material remain unresolved; no adoption clearance follows.

Dependencies: `bios.c` includes `h6280.h`, `globals.h`, `utils.h`, `pce.h` and
uses CPU state/accessors, IO, host CD backend, sector buffers, RAM/VRAM maps and
metadata. `cd.c` uses `cd.h`; `pcecd.c` includes `pce.h`/`utils.h` and uses the
same emulator subsystem. AUTHORS records unzip by Gilles Vollant, zlib, SDL
and SDLnet. Actual integration-specific transitive terms need a separate audit.
The BSD exception does not extend to calling GPL code or its dependencies.

Fit: selector names and HLE model help identify test hypotheses, but several
names/order conflict with HuCC; host exits, fallback execution and simplified
state updates do not specify a BIOS ABI. Historical discovery/hacking language
in `bios.c` means origin review remains pending, not clean-room certification.

Conditional obligations: GPL-covered source/binary incorporation needs the
applicable GPL terms, notices, modification records, corresponding-source
provision/source-offer route and distribution licensing review. No GPL code
may be folded into a ROM represented as MIT-only without a maintainer decision.
For separately cleared BSD code, preserve the exact source notices and binary
documentation notices and avoid unauthorized endorsement. Missing license and
attribution material must be resolved first. Disposition PENDING.

## Geargrafx

Repository: https://github.com/drhelius/Geargrafx

Revision: `b49ae82a012eade566d72e9d61c9d95a5caa4da3`; verified external checkout
HEAD and agreement with `tools/dependencies.json`. Targets: CPU/inline opcode
files, memory, CD controller and core plus the libretro build configuration; exact paths/hashes below.

Inspected core source headers name Ignacio Sanchez, copyright 2024, and GPL
version 3 or later. Root LICENSE contains GPL version 3. This file-level
or-later grant is more precise than a generic GPL-3.0 repository label.
Dependencies include core memory/video/input/audio/ADPCM/SCSI/media/trace state;
full application builds can also include desktop/UI/platform code and bundled
libchdr, lzma and minivorbis, whose own license files must remain separate.
This is not a complete application/transitive dependency clearance.

Fit: an external real CPU/hardware emulator suitable for original guest probes;
it is not a verified implementation of the target BIOS APIs. No emulator code
is included in this ledger/validator or proposed ROM. Parent work owns execution
harness and architectural probes; this audit does not claim those probes ran.
The pinned default libretro Makefile defines `GG_DISABLE_DISASSEMBLER`: prior
`RunToVBlank(debug.step_debugger=true)` results are bounded frame/halt
checkpoints, not instruction-step evidence. A separate debugger-enabled build
using the same archive SHA and no upstream patches, including a one-SEI/PC+1
check, is parent-owned pending work. The build configuration must accompany
any future execution evidence; the repository revision alone is insufficient.

Conditional obligations: redistributed GPL core/test executables require
applicable license/notices, corresponding source and modification/install
information where required; bundled dependencies retain separate terms. Keep
external test artifacts separate from MIT firmware and audit the actual link
and conveyance boundary before redistribution. Disposition PENDING.
