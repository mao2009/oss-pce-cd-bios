# CD_DINFO（スロット `$0B`、候補エントリ `$E021`）呼出側 ABI・呼出契約の根拠台帳（Issue #234）

**状態: 呼出先（System Card の callee）の ABI は未確定。ROM 実装なし。**
親 Issue #20、対象 Issue #234（Contract）。spec=HYPOTHESIS、provenance=PENDING、implementation=NOT_STARTED、verification=NOT_RUN。
**callee 側: BLOCKED_ABI。release_eligible=false。DEV_CALLABLE にしない。**

本台帳は、公開の呼出側ソースから読める事実と、呼出先の仮説・未確定を分けて記録する。
名前や呼出側のコメントから呼出先の ABI を導かない。未確定の欄には値を補わない。
照会種別は種別ごとに行を分け、BCD トラック・入力値・4 バイト出力の候補は根拠別に書く。

関連: #235 合成 TOC fixture（モデル期待値、callee ABI ではない。`tests/fixtures/cddinfo-slot0b-cases.json`）、#173 安全ゲート（参照 JSR 実行不可、JSR 0 回）。
実コア・純正 BIOS・実メディアの実行は未実施（NOT_RUN）。本台帳の PASS は System Card の動作の証拠ではない。

## 1. 規則

状態の意味:

- `SOURCE_FACT`: 固定版の公開ソースに書かれた事実。**呼出側（caller）の記述**か、**名前・入口の宣言**に限る。呼出先の振る舞いには付けない。
- `HYPOTHESIS`: 作者のコメント（試験プログラムの仕様記述）や、呼出側の入力源からの推測。実行で確認していない。
- `UNKNOWN`: 出典が不足している、または出典同士が食い違う。値の欄は `UNKNOWN` と書く。
- `BLOCKED_ABI`: 呼出先の ABI が未確定で、実行による測定もできない（実行可能な callee がない）。
- `CONFLICT`: 出典間で矛盾する項目は §4 に明示し、行としては UNKNOWN/HYPOTHESIS のまま残し、SOURCE_FACT にしない。
- `NOT_RUN`: 実行検証していない項目。ヘッダの verification 表記がこれに対応し、表のどの行も実行で裏づけていない。

禁止事項:

- `VERIFIED` と `OBSERVED` は使わない。呼出先を実行していないため、どの行にも付けられない。
- `PASS` と `DEV_CALLABLE` は使わない。callee は callable として実装されていない。
- `side` が `callee` の行は `HYPOTHESIS` / `UNKNOWN` / `BLOCKED_ABI` のみ。呼出側のソースから callee の事実を導かない。
- `SOURCE_FACT` の根拠は一次出典（S1〜S3）に限る。利用許諾が確認できない出典（S4）や名前のみの出典（S5）、リポジトリ内の棚卸し（S6）だけを根拠にしない。
- caller が戻り値を検査していることと、純正 callee がその戻り値を返すことは別である。前者を後者の事実にしない。

## 4. 出典間の食い違い（明示）

- 1. **戻り値の判定レジスタ**: 呼出側 S2 は Z で分岐し、作者コメントは Y・Z・N を挙げる。利用許諾未確認の S4 は A で判定する。どのレジスタが結果を運ぶかは F18・F19 で UNKNOWN のまま残す（CONFLICT）。
- 2. **出力バッファの位置**: S4 は BX に受信バッファを設定して渡すように読める。BSL-1.0 の S2・S3 は BX を設定せず、固定の受信バッファから読む。S2・S3 の固定バッファは試験側の実装であり、BIOS の出力先の証拠ではない（F11・F12、CONFLICT）。
- 3. **種別 3**: S2 の作者コメントは「文書化されているが、使えない値を返す」と書く。作者の観測であり、実行で未確認。種別 3 の挙動は F07（マスクの仮説）と F33（未対応種別の戻り、UNKNOWN）で扱う。
- 4. **トラックの形式**: S2 は種別 0 の結果を上位値に入れる。S4 は二進から BCD へ変換してから上位値に入れる。両方とも BCD を指すが、BIOS がそれを要求するかは F09 で未確認。
- 5. **版の違い**: 固定版の出典に、System Card の版（1.0、2.x、3.0）を示す記述はない。版による違いは確認できない（UNKNOWN）。Hu-Go の版差も原文照合が必要（F30）。

## 5. 除外・未転載

- 出典の本文（コード、表、命令列）は転載しない。台帳は行番号と作者の記述の要旨だけを記す。
- ROM の内容、逆アセンブル、BIOS のバイト列は読んでいない。`./rom/` は参照していない。純正 BIOS は使っていない。純正 BIOS への JSR は 0 回である。
- 展開した一式はリポジトリ外に置き、コミットしない。
- #235 の合成 TOC モデルは本台帳の callee 側を確定する根拠ではない。4 バイト出力候補は確定値として扱わない。

## 6. 残る UNKNOWN と決着条件

| 項目 | 決着の方法 |
| --- | --- |
| F10、F12（入力、出力バッファ位置） | 公開できる実行可能な callee で、BX と作業 RAM の値を変えて観測する。現時点では実行可能な callee がないため BLOCKED_ABI |
| F18〜F20、F31〜F33（戻り値の判定レジスタ、エラーコード、媒体なし・範囲外トラック・未対応種別） | 無ディスク、不正なトラック、busy のケースで A・Y・Z・N を全比較する |
| F22〜F24（X、フラグ、SP と復帰） | 呼出し前後の P・SP・X を全比較する |
| F25〜F28（MPR、副作用、IRQ2、busy） | IRQ マスクの有無を変えた試験、busy 中の呼出しの試験 |
| F13〜F15（4 バイトの内容） | 種別ごとに既知の合成媒体で出力を取得する。BCD かどうかと末尾の意味を分けて判定する |
| F30（参照実装）、版の違い | 人手で原文を照合する。ライセンスの扱いは maintainer が判断する |
