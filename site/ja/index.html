Open-source firmware / PC Engine CD

System Cardを、誰もが使えるOSSへ。

PCエンジン / TurboGrafx-CD向けの再配布可能なSystem Card BIOS代替実装を、独自コードと適切にライセンスされたOSSで開発しています。動作を確認できた範囲と、まだ分からない範囲を明確に公開します。

01 / ミッション

プラットフォームを残す。
ファームウェアを開く。

まず目指すのはSuper System Card 3.0のソフトウェア互換性です。独自にビルド・検証・再配布できるBIOSを育て、将来的に正規のゲームソフトを楽しむために別途プロプライエタリBIOSを用意する必要性を減らします。純正ROMや市販ゲームデータは配布しません。

検証基盤の構築

M1 / 進行中

呼び出せるBIOS API

EX_GETVERはGeargrafxで呼び出し・復帰を確認。純正ABIの全面的な検証やCDサービスの実装は未完了です。

M2 / 未達成

自作CDプログラム起動

合成CDからRAMへコードを読み込み実行できていますが、BIOSの起動・サービス経路を通したものではありません。

M3 / 未検証

市販ゲームとの互換性

市販ゲームの起動、別エミュレータとの照合、実機での互換性はまだ確認できていません。

重要：Geargrafxで診断処理が動くことと、純正System Cardと互換であることは別です。互換性やリリース可能性は認定しておらず、リリースゲートは閉じたままです。

✓

Geargrafx実コアで観測済み

EX_GETVERのcold/warm呼び出し・復帰、合成CDのREAD(6)からRAMへの転送、独立した初期化診断など。

!

未確定・未実装の領域

純正BIOSの完全なABI、CD_RESET/CD_BASE/CD_READの実API、自作CDのBIOS経由起動、別コア・実機の互換性。

04 / よくある質問

今、何ができるの？

検索やAIによる案内でも誤解が起きないよう、実装済みの機能と未検証の範囲を分けて説明します。

01 / 対応状況

実際のゲームで使えるBIOS？

まだ使えません。256KiBの開発用ROMには呼び出せるEX_GETVERが1件あり、残り80スロットは未実装です。市販ゲームの互換性や配布可能な製品版は未達成です。

02 / 検証

どこまで動作確認した？

Geargrafxの実コアでEX_GETVERの復帰と合成CDセクター読み込みを確認しています。ただし純正BIOSの完全なABI互換性やゲーム起動の証明ではありません。PR #174 を参照してください。

03 / 参加

開発に参加するには？

GitHub Issuesから仕様調査、テスト、独自実装に取り組めます。参加方針を確認し、純正BIOSデータをアップロードしないでください。

03 / コントリビューター

小さなIssueから、
確かな成果を。

BIOSのアセンブリ実装だけが貢献ではありません。仕様の根拠確認、再現テスト、文章の改善も大切です。まずIssueを確認し、観測結果と未検証事項を区別してPRを作ってください。
