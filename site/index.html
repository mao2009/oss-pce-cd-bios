01 / Mission

Preserve the platform.
Open the firmware.

Our first target is software compatibility with Super System Card 3.0. We want developers and preservationists to study, build, test, and eventually use an openly redistributable BIOS—without shipping proprietary firmware or commercial game data.

01 — ACCESS

An open alternative

Make a reproducible System Card implementation that can eventually remove the need to supply a proprietary BIOS image.

02 — EVIDENCE

Measured, not assumed

Separate host models, real emulator observations, reference contracts, and actual game compatibility. No passing labels without proof.

03 — COMMUNITY

Built in the open

Keep the source, tests, provenance reviews, and unresolved questions accessible so contributors can take on focused work.

M0 / Foundation · largely established

Repeatable diagnostics

Toolchain, DEV ROM layout, real-core CPU/RAM checks, and synthetic CD sector transfer. Some ROM/ABI research remains.

M1 / In progress

Callable firmware APIs

EX_GETVER executes and returns in Geargrafx; reference ABI is not fully verified. CD services remain unimplemented.

M2 / Not yet achieved

Homebrew disc boot

Synthetic CD → RAM code execution is proven as a diagnostic, but not through the BIOS startup/service path.

M3 / Not tested

Retail compatibility

No verified commercial-game boot, second-emulator validation, or physical-hardware compatibility claim.

Important distinction: Geargrafx executing a diagnostic is not the same as the System Card API contract being verified, a game booting, or a production BIOS being ready. The release gate remains blocked.

✓

Observed on a real emulator core

EX_GETVER caller return (cold/warm); synthetic SCSI READ(6) → RAM; independent reset and startup diagnostics.

!

Still unknown or blocked

Full reference BIOS ABI, callable CD_RESET/CD_BASE/CD_READ, BIOS-mediated disc boot, independent emulator and hardware results.

◇
Provenance is part of the contribution.

Do not submit proprietary System Card ROMs, commercial discs, protected code, or private binary extracts. Reused OSS needs a file-level license/provenance review and human approval before inclusion. Synthetic test inputs do not require a private BIOS. Read CONTRIBUTING.md and the reuse policy.

Help make open firmware real.
