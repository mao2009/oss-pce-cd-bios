## 3. 訂正（#503 の記述に対する追加）

* **`_dh = 6` の追加**: HuCC `core-kernel.asm` L593 に `lda #6`、L594 に `sta <_dh`、L596 に `jsr cd_read` がある。`cd_read` の呼出し箇所は、`hucc-systemcard.asm` の 4 箇所と合わせて計 5 箇所で、値は `$FF`、`$FE`、`0`、`3`、`6`。#503 の一覧（0 / 3 / $FE / $FF / 6）と一致する。`include/huc/` は未検査。
* **`tax` の行番号**: `hucc-systemcard.asm` の `tax` は L448。#503 と本書の R-1 の範囲 L448-455 は正しい。
* **mode 0 の上限**: `$2000` は呼出側の 8KB 分割単位（`cmp.h #$2000` による分割ループ）であり、callee の上限ではない。
* **B-2 の参照先**: 基点の未解決矛盾は `docs/research/148-cd-read-abi.md` §6 を参照。
