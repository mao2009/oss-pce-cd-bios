# 過去の公開履歴の残存リスク

この文書は、過去に公開された情報が、現在の HEAD に残らない範囲でも、履歴には残る可能性があることを記録する。値、コミットの所在、PR・Issue の一覧は掲載しない。

## 状況

- 過去の Git 履歴に、識別情報を含む情報が残る可能性がある。
- 過去の PR・Issue の編集履歴に、元の本文が残る可能性がある。
- 現行 HEAD の修正だけでは、これらを消去できない。
- 履歴の書換え、force push、既存の監査証拠の削除は行っていない。
- 詳細な履歴監査記録は、リポジトリ外の限られた保管場所で管理する。その所在は、この公開文書には記載しない。

## 扱い

- この残存リスクは、現行 HEAD の公開境界の判定とは別に管理する。
- オーナーは、この残存リスクを本 PR の修正範囲外として受容している。受容は、過去の情報が消えたこと、または公開によるリスクがなくなったことを意味しない。
- 外部の clone、キャッシュ、アーカイブに残る可能性がある。これは機械的に確認できない。

## 再評価する条件

- 過去のコミットを含む公開範囲の方針が変わったとき。
- 外部の clone、キャッシュ、アーカイブへの露出が確認されたとき。
- 新しい漏えい経路が見つかったとき。新しい経路は、このリスクとは別に BLOCKED として扱う。
