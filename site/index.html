01 / Mission

Preserve the platform.
Open the firmware.

Our first target is software compatibility with Super System Card 3.0. We want developers and preservationists to study, build, test, and eventually use an openly redistributable BIOS—without shipping proprietary firmware or commercial game data.

01 — ACCESS

An open alternative

Make a reproducible System Card implementation that can eventually remove the need to supply a proprietary BIOS image.

02 — EVIDENCE

Measured, not assumed

Separate host models, real emulator observations, reference contracts, and actual game compatibility. No passing labels without proof.

03 — COMMUNITY

Built in the open

Keep the source, tests, provenance reviews, and unresolved questions accessible so contributors can take on focused work.

05 / Frequently asked questions

What does the project actually support?

A short, source-linked summary for developers, researchers and anyone discovering this open-source PC Engine CD BIOS effort.

01 / SCOPE

Is it a usable System Card BIOS?

Not yet. The 256 KiB development ROM has nine DEV-only implemented APIs (EX_GETVER, EX_BINBCD, EX_BCDBIN, MA_MUL8U, MA_MUL8S, MA_MUL16U, MA_DIV16S, MA_DIV16U, MA_MUL16S; none approved or ABI-verified), while 72 other slots remain stubs. No retail-game compatibility or firmware release is established.

02 / EVIDENCE

What has been tested?

Geargrafx real-core tests observe EX_GETVER return, DEV-only arithmetic including MA_DIV16U, and synthetic CD sector reads. A separate synthetic stack experiment exposed unsafe I/O-mapped pushes. These diagnostics do not certify reference-BIOS ABI compatibility or game boot. See PR #174.

03 / CONTRIBUTE

How can I help?

Start with a focused GitHub Issue covering API research, reproducible testing or original firmware code. Follow the contribution policy and do not upload private BIOS images.

Help make open firmware real.
