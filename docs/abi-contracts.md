# ABI 契約台帳（公開管理情報）

この文書は、公開リポジトリの ABI 契約台帳の**管理情報**だけを説明する。参照 BIOS の ABI を検証したものではなく、互換性や起動可能性を主張するものでもない。

## 公開する状態

| 状態 | 意味 |
|---|---|
| `UNVERIFIED` | 参照 BIOS の ABI は検証されていない。 |
| `BLOCKED` | 検証や公開を進められない理由がある。 |
| `NOT_RUN` | 承認済みの検証経路における記録状態である。過去の試行の有無を示すものではない。 |
| `release_eligible: false` | リリース判定は許可されていない。 |

- 参照 BIOS の ABI 状態は、全スロットで `UNVERIFIED` である。`VERIFIED` は台帳に存在しない。
- 参照 JSR の実行ゲート（`tools/reference_jsr_gate.py`）は全スロットで閉じている。
- DEV ROM の実装は、DEV 専用の自己定義契約であり、参照 BIOS の値を証明しない。

## 公開しない情報

非公開の参照 BIOS 由来の解析・観測・実行に関する情報は、値だけでなく、その存在を示すメタデータも公開しない。これには、識別値、入口テーブルの構造、命令・制御フロー、ハザード、スロット別の解析結果が含まれる。

## 未確定事項

- 81 スロットの入口情報は、公開ソースで独立に確認されたものだけを公開する方針である。出典の確認は未了であり、現在の台帳に残る候補入口は未解決のリスクとして扱う。
- 公開ソースで確認できない情報は、未確定として扱う。

この台帳の状態は、ABI 検証、provenance 承認、DEV_CALLABLE 承認、release gate の解除を意味しない。
