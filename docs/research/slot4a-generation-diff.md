## 分類の定義

各項目の分類は次の 6 値のいずれか。判定は公開資料のみによる。

| 分類 | 意味 |
|---|---|
| `SOURCE_FACT` | ピン留めした一次資料が明示する呼出側事実。callee の挙動としては使わない。 |
| `CORROBORATED` | 独立な 2 出典以上が一致する（著者・系統が別）。 |
| `HYPOTHESIS` | 単一出典の記述、または出典からの推論。信頼度は `SOURCE_SUPPORTED` に留まる。 |
| `UNKNOWN` | 信頼すべき出典がない。 |
| `CONFLICT` | 出典相互で食い違う、または対立する読みがある。 |
| `BLOCKED` | 判定に参照実行や一次資料の確認が必要で、安全ゲートと方針による。 |

`SOURCE_FACT` / `HYPOTHESIS` は、調査した出典の述べたことであり、
純正 callee の実測ではない。`HYPOTHESIS` を昇格の根拠にしない。
`spec/api_contracts.json` の対象行
（`mapping_status: HYPOTHESIS`、契約項目はすべて `UNKNOWN`、
`provenance_status: PENDING`、`implementation_status: NOT_STARTED`、
`verification: NOT_RUN`）は変更しない。
`spec/dev_implementations.json` の対象行（`NOT_READY`、実装なし）は
変更しない。

### 解釈上の注意

- 入口のジャンプテーブル位置は許可台帳の配置規則の範囲でのみ扱う。
  値の再掲はしない。内部先の確定は F01 の通り信頼度が下がる。
- S1 の作業 RAM 割付けは呼出側の `SOURCE_FACT` として成立しうるが、
  callee の挙動（F03・F08）としては使わない。軸の分離は
  `docs/abi-evidence-classification.md` に従う。
- S2 の選択子は HLE 内部の振分けの事実であり、純正の実行入口や
  世代の事実ではない。
- S3 が本件を記録していない場合は、不記載の記録に留め、
  支持の存在も不存在も結論しない。
- S4 の世代別の主張は単一二次系統の主張である。対象版の確定には
  一次資料と人間の承認が必要であり、本書では `BLOCKED` とする。
